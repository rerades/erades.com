# Theme Toggle

> Generado por `pnpm docs:components` desde [`ThemeToggle.astro`](../../src/components/ThemeToggle.astro). No editar a mano.

El interruptor de tema claro/oscuro. La preferencia se guarda en `localStorage` y se aplica antes de pintar, para que no haya un fogonazo blanco al cargar en oscuro.
